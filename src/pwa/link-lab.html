How provider selection works

Link Lab reads the same local provider registry and custom-builder settings as the PWA. A configured provider is preferred when it matches the requested capability; otherwise a recommended active provider is selected. Changing a provider inside Link Lab affects only this comparison and does not rewrite your global Settings.

Retired providers remain readable only for migration compatibility and are not offered as active outputs. Link Lab does not send background requests to providers to check whether they are online.
