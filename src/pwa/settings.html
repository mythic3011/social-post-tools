Provider lifecycle

Built-in providers

No live probing

The app keeps a curated built-in set instead of shipping a long list of public instances. Runtime health probing stays disabled for privacy and CSP simplicity.

04 · AI capture handoff

The PWA can be installed by Chrome for Share Target support while rich capture opens in the browser that has the Userscript.

05 · Custom providers

Advanced: add a self-hosted reader, embed service, or URL template. HTTPS is required except loopback.

06 · Transfer or reset

Portable settings let the browser Userscript and Android companion share the same custom link builders.

Mental model

Three different outputs

Embed
Link optimized for chat previews.
Reader
Alternative frontend for reading.
Privacy

Provider checks stay explicit

The PWA does not silently contact every alternate frontend to test availability. That would leak browsing intent and complicate the current CSP.
