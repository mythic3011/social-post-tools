Two steps, then you are done.

The browser version is a Userscript. Install a Userscript manager once, then install Social Post Tools.

Already use Tampermonkey or Violentmonkey? Skip directly to step 2.

1

One-time setup

Install a Userscript manager

A Userscript manager is the browser extension that installs and updates .user.js files.

TampermonkeyRecommended

Straightforward choice for most users. The official site routes you to the appropriate browser install.

Get Tampermonkey ↗
ViolentmonkeyOpen source

An open-source Userscript manager and a compatible alternative.

Get Violentmonkey ↗

Use the official manager site. Social Post Tools does not bundle or redistribute a browser extension.

2

Social Post Tools

Install the Userscript

After the manager is installed and enabled, open the Userscript file below. Your manager should show its install/confirm screen.

Install Social Post Tools Userscript

If you only see JavaScript source code: the Userscript manager is probably missing, disabled, or not handling .user.js links. Finish step 1, then try again.

3

Use it

Open X or Threads

Open a post, use its Share menu, then choose Post tools. Recommended defaults work without additional configuration.

Open X ↗ Open Threads ↗

Using Android native apps instead?

The Android companion is usually simpler when you want to share directly from the native X or Threads app. Return home and install the Android app from the browser.
