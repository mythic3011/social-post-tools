04 · Troubleshooting direct install

If a .user.js link opens as JavaScript source instead of an install prompt, first confirm the Userscript manager is installed and enabled. Then try the Raw GitHub route above.

Tampermonkey also provides Options → Utilities → Import from URL, which is useful when browser URL interception is unavailable.

Why three sources?

No single hosting dependency

The website can stay friendly, Raw GitHub can remain a plain install/update endpoint, and jsDelivr can act as a delivery fallback without becoming the authority.
