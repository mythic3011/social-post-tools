# Security

The detailed threat boundaries, storage rules, media-fetch policy, archive integrity model, UI dependency policy, and GitHub Pages deployment assumptions live in [`docs/architecture/SECURITY_MODEL.md`](docs/architecture/SECURITY_MODEL.md).

For browser installation, use the official Userscript-manager sites linked by this project:

- [Tampermonkey](https://www.tampermonkey.net/)
- [Violentmonkey](https://violentmonkey.github.io/)

Social Post Tools does not redistribute those browser extensions. The project-hosted Userscript is served from `share-tools.mythic3011.com/install/`.

Do not put credentials, session cookies, private post contents, or other secrets in public bug reports.
