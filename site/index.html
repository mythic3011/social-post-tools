Browser Userscript

Best for X / Threads in the browser.

2-step setup

The Userscript adds Post tools to X and Threads while keeping the site's native menu style.

1. Get a Userscript managerTampermonkey is the recommended default; Violentmonkey is also supported.
2. Install Social Post ToolsThe manager handles the .user.js install and future updates.
Browser setup Get Tampermonkey ↗

Already have Tampermonkey or Violentmonkey? Install the Userscript directly.

Install Social Post Tools

Open your browser menu, then choose Install app or Add to Home screen.

The custom install prompt is browser-dependent. Manual installation can still work even when this website cannot trigger the browser prompt directly.
